# GAS Agent Skills 1.5

发布日期：2026-10-02。发行版本为 1.5；集权、分权与组合运行契约 schema 仍分别为 3、2、1。

## 主要变化

- 全部治理角色由真实子 agent 承担：集权默认 4 个、分权 3 个、组合 6 个；主会话另计，仅展示进展和承载人类交互。缺席时等待补齐，不由主会话接任。
- 三技能均提供独立可运行的 `gas_runtime.py`，生成及校验候选清单、证据摘要与运行记录，区分执行事实、技术结论、风险接受和交付。
- 补充关键能力预检、四阶段启动回执、检查点与未知副作用恢复规则。
- 集权增加进展账本与有界重规划；分权细化结构化验收；组合明确两层依赖、方法独立性及原始证据复用。
- 增加真实文件故障实验、角色承载反例和组合静态检查；首页用当前架构图替代包含旧主会话任职安排的图片。

原有人类模型／推理强度选择、职责确认、等待、TEAM_READY、服务档位继承及各模式治理权责保留。已有记录升级时应重新核对角色承载，不能将旧主会话身份直接当作新的子 agent 记录。

## 验证与限制

发布校验采用全包和单技能静态检查、包回归、集权原回归及安装冒烟。Windows 本地回归共 148 项，147 项通过，1 项因符号链接权限不足跳过。三模式 54 次文件故障实验符合预期；完整治理团队性能对照未运行，治理场景仍为 NOT_RUN。

详细结果见 [VALIDATION.md](../../GAS-Agent-Skills/VALIDATION.md)，机制说明见 [策略改进](../three-skill-strategy-upgrade-2026-10-01.md) 和 [角色承载](../role-subagents-2026-10-02.md)。GitHub Actions 的实际状态以该发布提交对应的运行记录为准。

## 获取与升级

使用仓库 `v1.5` 标签下载完整源码，或切换到该标签。安装时保持三个技能目录同级并复制完整目录；组合依赖另两个技能。原安装器仍拒绝覆盖现有目录，请先备份并保留已有自定义修改。

下载的第三方源码、论文及本机审计备份不随本版本上传。摘要证明文件一致性，不是发布者数字签名，也不证明完整治理运行成功。
