# GAS Agent Skills 2.0

发布日期：2026-10-05（Asia/Shanghai）。发行版本为 2.0；集权、分权与组合运行契约 schema 仍分别为 3、2、1，共同 runtime 附表为 schema 1。历史 v1.x 标签不改写。

## 主要变化

- 审查者接收执行者与监督者输出，独立分析问题及证据缺口，不编写或修改测试／验证代码；代码补证交具名执行者。分权裁衡者与组合外层裁衡者遵循相同代码归属边界，可复跑已有获准命令并作独立判断。
- 执行者数量 N 可由用户指定，默认 1。每人负责独立模块开发和该项验证，绑定任务、路径、测试代码、身份与证据。集权 N+3、分权 N+2、组合内层 N 时 N+5 个真实子 agent，各另加展示主会话；组合唯一外层执行者／内层指挥者桥接关系保留。
- 集权及组合监督者对照指挥者意图监督全部执行者和审查者，监测板卡电压、电流、运行、agent 状态及软硬件异常。采样记录来源、单位、阈值、采样与评估时刻及有效窗口；过期、缺测或依据未知不得记为安全。分权不新增监督或指挥席，由各执行者共享监控事实、裁衡者分析异常。
- 指挥者主动并行所有就绪独立任务；开发、验证、已有产物分析与监控可重叠。真实依赖、文件冲突、共享板卡烧录／调试、预算及宿主上限约束相应动作；设备锁不因超时自动释放。
- 普通执行者失联替换须撤销旧指令并核对旧写入／设备控制停止或撤权，重绑定开发和验证职责后恢复全员就绪。单通道监测缺口与整个监督角色失能分别处理。
- 纳入 2026-10-04 外部评审修订：组合校验与场景覆盖、安装默认 `.agents/skills`、只读默认的清单／共享资料维护工具、无效证据真实漂移检测、链接夹具核实及 GBK 输出回执修复。CI 显式运行并归档 54 次文件故障实验。

## 升级注意

原有人类模型／推理强度与职责确认、等待、TEAM_READY、服务档位继承、授权、预算、独立审查、精确候选及发布门禁保留。角色配置支持多执行者后，旧单人字段只描述兼容默认，不证明完整 N 人名单或监控已建立。实际记录补齐具名所有权、资源和观测依据，并重新核对全部计划成员。

保持三个技能目录同级，复制完整目录；组合依赖集权与分权。安装器仍拒绝覆盖既有同名目录，升级前备份并保留自定义修改。发行版本不是记录 schema 版本，不能批量把 schema_version 改成 2.0。

## 验证与限制

发布前运行全包／单技能静态核验、包回归与集权回归、54 次真实文件故障实验、暂存安装及 Git 发布字节摘要核对。实际结果与解释见 [验证记录](../../GAS-Agent-Skills/VALIDATION.md)。GitHub Actions 状态以本版本提交和标签对应的运行记录为准。

62／38／19 个治理场景保持 NOT_RUN；本轮文件和离线检查不证明完整治理团队性能、真实板卡安全或宿主后台监控已实现。5 项本机回归跳过源于真实 symlink 权限限制，不能代替其他平台实测。未知成本与用量不填零。
