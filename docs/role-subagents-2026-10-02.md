# 三技能全角色子 agent 修订

本规则纳入 [1.5](releases/1.5.md)：所有治理角色由真实子 agent 承担，主会话显示进展、承载人类交互，不占角色席位。

| 模式 | 完整默认治理子 agent | 总会话数 |
| --- | --- | --- |
| 集权 | 4 个：指挥者、执行者、审查者、监督者 | 5，含展示主会话 |
| 分权 | 3 个：立规者、执行者、裁衡者 | 4，含展示主会话 |
| 组合 | 6 个：外层立规者、桥接执行者／指挥者、外层裁衡者、内层执行者、审查者、监督者 | 7，含展示主会话 |

主会话不做业务分析、实施、测试、技术裁决、验收或发布。宿主只在主会话提供创建／消息工具时，按已确认名单或具名治理子 agent 的原始指令机械转接，保留发起者与回执；工具父子树不改变角色权力。主会话不得借转接决定任务优先级或改写验收结论。

全部角色齐备并满足 TEAM_READY 后，由对应子 agent 检查业务项目并开展工作。缺席时展示等待与缺口，不能由主会话接任。组合外层执行者与内层指挥者仍为同一子 agent。

运行模板新增 `main_session` 和 `role_hosting`。真实 roster 应包含子 agent 身份、角色覆盖、创建回执、职责确认与就绪回执。空名单和 `verified=false` 不能当作已经核验。模板校验器不会认证宿主关系，也不创建强制权限隔离。

原角色职权、独立验收、模型／推理强度与职责确认、等待、服务档位及全员就绪规则保留。旧 run schema 分别为 3、2、1。

## 验证范围

新增 19 项角色承载反例测试，覆盖主会话占席／业务许可、错误角色人数或类型、缺失或重复角色、伪造 roster、默认已核验及畸形结构。协议审查发现的组建前业务分析和旧图误导问题均已修复；旧图片保留为明确标注的历史参考。

独立文档使用探针对槽位不足、主会话机械转接、角色失联、代做测试及启动检查时机作出符合规则的安排。此项属于文字判读，不是实际团队运行。治理场景为 48／32／11 个，仍全部 NOT_RUN。

完整测试结果见 [验证记录](../GAS-Agent-Skills/VALIDATION.md)。本机运行日志、安装回执和旧版备份保存在作者本地，不属于公开仓库运行依赖，也不随下载包提供。
