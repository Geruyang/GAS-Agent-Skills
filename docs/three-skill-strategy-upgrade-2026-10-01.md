# 三技能策略改进

本轮七项策略改进纳入 [1.5](releases/1.5.md)，对应文件位于 [技能包](../GAS-Agent-Skills/README.zh-CN.md)。固定版本的研究来源及采用边界见 [研究借鉴说明](../GAS-Agent-Skills/gas-centralized-development/references/research-basis.md)。

| 策略 | 实现 |
| --- | --- |
| 验收状态与例外 | 分开检查执行、事实结论、风险接受、人类决定和交付；风险接受不能将失败或缺失检查变成 PASS。 |
| 提前验证关键能力 | 全员就绪后用代表性输入检查实际输出；支持文本断言、二进制摘要及保留源输入摘要的预检复用。有限试验许可消除预检与契约生效的循环。 |
| 启动、回执与恢复 | 分开发出、接收、开始、完成，核对运行、任务、接收者、任期、契约、候选及幂等键。未知副作用先查询，不盲重试。 |
| 自动证据清单 | 每个技能独立携带标准库 CLI：manifest、verify、assess；检查文件、空目录、证据绑定、候选变化及结束读回。 |
| 治理与执行结构分开 | 登记可拆分性、依赖、共享状态、失败后果和执行拓扑，建议不自动改变用户所选治理模式。 |
| 分层审查与方法独立性 | 分权细化逐项验收及计划／实测覆盖；组合区分准备意见和最终裁衡，明确无环依赖与原始证据复用条件。 |
| 真实实验与评价口径 | 提供同输入真实文件／CLI 故障实验执行器，记录误通过、实际耗时及未知成本。完整治理团队对照尚未执行。 |

集权补充任务与进展账本、停滞原因、剩余预算和有界重规划。分权保留三席平级、唯一执行者和独立裁衡。组合保持桥接同一身份及一次交付、两层引用。所有治理角色现在均由子 agent 承担，详见 [角色承载修订](role-subagents-2026-10-02.md)。

## 工具与验证

各技能的 `references/runtime-evidence.md` 说明记录格式和 CLI。清单、运行记录及证据应保存到实际项目中，不写回技能示例。模板保持未执行、未批准及未知状态。

三模式各 18 例、共 54 次本地文件故障实验符合预期，误通过 0；独立工具审查覆盖候选／证据读回、路径别名、重试类型、回执绑定及历史预检复用。另有三个新代理各 4 次真实 CLI 使用探针。测试仅说明所测输入下的工具行为，不构成治理优劣或模型能力提高的证明。

`technical_evidence_ready` 仅核对已声明记录和文件，不证明契约覆盖完整、证据语义正确、授权有效或角色独立。结束读回不是锁，应在受控冻结目录中使用。技术条件就绪不等于管理接受、外层裁衡通过或交付完成。

完整结果与环境限制见 [验证记录](../GAS-Agent-Skills/VALIDATION.md)。下载的研究资料、历史交接、原始运行日志及本机备份留在作者本地，不随公开仓库提供；公开技能不依赖这些本地路径。
