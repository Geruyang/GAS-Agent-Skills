# 一局象棋 · 组合实验版

原生 HTML / CSS / ES modules，本地双人轮流对弈，无外部依赖或网络素材。

从 `experiments/xiangqi` 运行 `node serve.mjs`，打开服务器对应的 `/combined/`。实验共享预览地址为 http://127.0.0.1:8765/combined/ 。请通过 HTTP 打开，ES modules 不适合直接双击 file URL。

## 操作

- 红方先行，选择己方棋子后点击圆点落子或虚线圈吃子。选中棋子有轮廓和菱形标记，状态区说明合法着数量。
- 棋盘有单一 Tab 入口；方向键移动焦点，Enter 或空格选子/落子，Esc 取消选择。所有棋位有中文名称与固定坐标。
- 悔棋撤销一手（恢复轮次与终局状态），重新开始清空棋谱，翻转仅改变观看方向。
- 棋谱使用固定 A–I 列与 1–10 行，从黑方左上起算；翻转后坐标不变。

支持所有合同指定规则、将军、自陷将军过滤、将帅照面、将死、困毙、缺将判负与终局锁定。不裁定比赛长将/长捉，不支持联网、AI、竞赛计时或存档。刷新页面会开启新局。

## 架构与检查

`engine.js` 只处理纯棋盘数据：几何攻击检测与合法着过滤分离，移动深拷贝棋盘。`app.js` 管理当前轮次、独立历史局面、操作反馈与显示方向。棋线使用内联 SVG，90 个棋位使用真实按钮，窄屏纵排。

在 `experiments/xiangqi` 下：

```powershell
$env:XIANGQI_MODE='combined'
node --test tests/acceptance.test.mjs
node --test combined/engine.test.mjs
```

补充测试检查开局 44 着与红黑旋转对称、八向马腿、炮将应将、将帅吃子安全、飞将终局、黑方困毙/将死、非法输入、冻结输入、100 手确定性走棋不变量。

视觉采用米纸、木色、墨色与朱红，以棋盤和清楚状态为核心。UI 检索返回营销/3D与绿金色方案，不适合固定 brief；只采纳键盘焦点、减少动效与窄屏检查原则，未使用网络字体或 3D 素材。

自测与 SHA256 清单位于 `.gas/runs/xiangqi-v2-combined/inner/executor/`（相对仓库根目录）。浏览器验证与独立审查由其他真实席位记录；本文件不声明产品已接受或发布。
